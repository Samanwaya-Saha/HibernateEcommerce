# HibernateEcommerce

HibernateEcommerce is a Java-based e-commerce backend project developed using **Java, Hibernate ORM, JPA, MySQL, and Maven**. The project demonstrates how to map Java entities to database tables and perform database operations using Hibernate.

## Description

This project implements an e-commerce database system with entities such as **Category, Product, User, Orders, and Orderdetails**. It demonstrates relationships including **One-to-Many and Many-to-One**, along with cascading and lazy fetching.

The project also includes CRUD operations for creating categories, products, users, and orders, as well as retrieving orders with their associated users, products, and order details.

### Key Features

- Hibernate ORM and JPA entity mapping
- MySQL database integration
- One-to-Many and Many-to-One relationships
- Cascade operations
- Lazy fetching
- Category and product management
- User creation
- Order creation with multiple order details
- Fetching orders with associated users and products
- Maven-based project structure
- Git and GitHub version control

### Technologies Used

- Java
- Hibernate ORM
- JPA / Jakarta Persistence
- MySQL
- Maven
- Eclipse IDE
- Git & GitHub
